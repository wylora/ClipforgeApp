# ClipForge — AI-нарезка длинных видео на Shorts / TikTok / Reels

Вставляете ссылку или выбираете файл → выбираете режим («Смешные», «Серьёзные», «Лучшие», «Свой сценарий») →
программа расшифровывает речь, анализирует звук и видеоряд, оценивает эпизоды, вырезает лучшие, добавляет
субтитры, кадрирует в 9:16, сводит звук с музыкой (с автоприглушением) и сохраняет готовые MP4.

> **Честно о статусе.** Ядро (анализ, отбор, монтаж, звук, очередь, БД) покрыто тестами и прогнано на синтетическом
> видео в Linux. **Графический интерфейс PySide6, faster-whisper и yt-dlp в среде разработки не запускались**
> (не было сети) — GUI проверен только на синтаксис и согласованность вызовов. При первом запуске на Windows
> возможны мелкие недочёты интерфейса; сообщайте — они правятся локально, архитектура этого не требует
> переписывания. Качество определения юмора — эвристическое (см. «Ограничения»).

## Установка на Windows

1. **Python 3.11 или 3.12** — https://www.python.org/downloads/ (отметьте «Add python.exe to PATH»).
2. **FFmpeg** (нужна сборка с libass — для субтитров). Любой из вариантов:
   * `winget install Gyan.FFmpeg` (затем откройте новое окно терминала), или
   * скачайте «release full/essentials» с https://www.gyan.dev/ffmpeg/builds/, распакуйте, добавьте папку `bin` в `PATH`,
     **или** положите `ffmpeg.exe` и `ffprobe.exe` в папку `bin` рядом с `main.py`, **или** укажите папку в
     Настройки → Анализ и система → «Папка с ffmpeg».
   * Проверка: `ffmpeg -version`.
3. Зависимости:
   ```bat
   cd путь\к\clipforge_app
   py -3.11 -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   ```
   (или просто запустите `run.bat` — он сделает всё сам).
4. **Модель Whisper** скачивается автоматически при первом анализе — только после вашего согласия (диалог/галочка
   в настройках). Размеры: tiny ~75 МБ, base ~145 МБ, small ~480 МБ (рекомендуется), medium ~1.5 ГБ, large-v3 ~3 ГБ.
   Для NVIDIA GPU: установите CUDA 12 + cuDNN 9 (требование ctranslate2), выберите «Устройство → GPU».
5. Запуск: `python main.py` (или `run.bat`).

## Как пользоваться

1. **Главная:** вставьте ссылку и нажмите «Добавить ссылку» (отметьте галочку о правах на видео) и/или «Выбрать
   файлы…». В списке видно название, длительность, разрешение, размер. Можно добавить несколько видео — они встанут в очередь.
2. Выберите **режим**; для «Свой сценарий» опишите запрос («Найди все смешные реакции ведущего», «Выбери самые
   интересные истории», «Найди моменты с неожиданной развязкой»).
3. (Опционально) **Настройки:** длительность, число клипов, порог качества, формат кадра, субтитры, музыка, профиль монтажа.
4. **«Начать анализ»** → страница «Анализ»: этап, проценты, оставшееся время, лог, кнопка остановки.
5. По завершении откроется **галерея**: миниатюры, оценки, причины выбора, заголовки/хештеги, избранное, отметки
   «смешно / не смешно / интересно / скучно», повторный экспорт, удаление, открытие папки. Двойной клик — **редактор**:
   сдвиг границ на шкале времени, правка субтитров (текст и тайминги), громкость/музыка, кадрирование, сравнение с
   оригиналом, быстрый предпросмотр и «Пересобрать клип». История и возобновление — вкладка «История».

Готовые файлы: `Папка_результатов/<название>_<N>/01_название.mp4`, рядом `.srt`, `.jpg`, а в папке проекта `report.md/json`.

### Без Whisper
Положите файл `.srt`/`.vtt` с тем же именем рядом с видео — он будет использован вместо распознавания
(время слов внутри реплики распределяется равномерно). Для YouTube-видео без Whisper можно скачать субтитры отдельно.

### Консоль (для отладки)
```
python main.py --selfcheck                         # зависимости + сквозной прогон на тестовом видео
python main.py --cli video.mp4 --mode funny --clips 5
```

Что работает локально и что требует дополнительного:

| Функция | Требуется |
|---|---|
| Анализ звука/видео, отбор, монтаж, субтитры, музыка, ducking, эффекты | только FFmpeg + NumPy + OpenCV |
| Распознавание речи | `faster-whisper` + модель (скачивание с согласия) **или** готовый `.srt` |
| Загрузка по ссылке | `yt-dlp` + интернет |
| Оценка кандидатов LLM, перевод субтитров, заголовки от LLM | локальный сервер (Ollama/LM Studio) или облачный API; **выключено по умолчанию** |

## Как работает отбор моментов

1. Текст делится на смысловые единицы (по пунктуации и паузам; слова с временными метками).
2. Каждая реплика получает быструю оценку (маркеры шуток/неожиданности/смеха или фактов/выводов/советов + звуковые
   сигналы); выбираются сильнейшие **якоря** с подавлением соседей.
3. Вокруг якоря перебираются пары границ (начало/конец) по смысловым единицам: нужна подводка, пауза, кульминация,
   реакция (смех досматривается до конца), границы на паузах/концах фраз, нет зависимого начала («и тогда он…»).
   Короткая шутка не растягивается; у «серьёзных» эпизодов мысль доводится до конца.
4. Эпизод оценивается: `semantic`, `humor`, `reaction`, `audio`, `completeness`, `visual`; итог `quality` —
   взвешенная сумма (веса в Настройках → Клипы, по режимам).
   **Юмор 0–100** строится из независимых сигналов (текст, структура «сетап→пауза→панчлайн», звук, реакция, мимика).
   Один сигнал не может дать высокую оценку: потолок зависит от числа сильных независимых семейств сигналов.
5. Слабые кандидаты отбрасываются; дубли (пересечение, похожие кадры по dHash, похожий текст) удаляются; берутся лучшие N.
   Если хороших моментов нет — клипы **не создаются**, пользователю сообщается лучший балл и что можно изменить.
6. Для каждого клипа сохраняются оценки и текстовое объяснение («Почему выбран») — в галерее и в `report.md`.

**Обратная связь:** отметки сохраняются в SQLite; при ≥ 8 отметках обеих полярностей по группе («юмор» / «общее»)
обучается простая логистическая регрессия на 6 оценках, ее влияние на рейтинг ограничено (до 35 %). Это мягкая
персонализация, а не обучение нейросети.

## Музыка и лицензии
* Встроенная «подборка» синтезируется самой программой (лицензия CC0): простые подложки пяти настроений.
* Для качественной музыки положите файлы в каталог (Настройки → Музыка → «Открыть каталог») и опишите их в `catalog.json`:
  `[{"file":"track.mp3","mood":"calm","license":"CC-BY 4.0","source":"https://…"}]`. Автоподбор использует **только**
  треки с указанной лицензией. Файл, выбранный вручную, используется на ваше усмотрение и ответственность.
* В режиме «Авто» музыка **не** добавляется к смешным клипам (ухудшает комический эффект); режим «Всегда» это отменяет.
* Ducking: `sidechaincompress` — музыка тише, пока звучит речь, и плавно возвращается в паузах.
  Оригинал 0–200 % (выше 100 % — с ограничителем от клиппинга), музыка 0–100 %, интенсивность приглушения 0–100.

## Права на видео
Загрузка по ссылке разрешена только после подтверждения, что у вас есть право скачивать и обрабатывать видео
(соблюдайте условия площадки и авторские права). Локальные файлы — полноценная альтернатива.

## Ограничения (честно)
* Определение юмора — вероятностная эвристика; она ошибается (особенно в сарказме, иронии, неязыковом юморе).
  Лексиконы — русский и английский; для других языков работают звук, видео, структура и (опционально) LLM.
* Детектор смеха — эвристика по ритму огибающей; в шумных записях и при музыке даёт ложные срабатывания.
* Мимика оценивается косвенно (движение области рта, каскады Хаара); «активный говорящий» — по движению рта,
  без модели синхронизации губ и речи. Определение смены говорящих — грубая кластеризация по тону/тембру.
* Умный кроп отслеживает лица на 5 к/с; профильные/мелкие лица Хаара может пропускать (тогда — центральный кроп).
* Нарезка перекодируется (точность по кадру, а не по ключевым кадрам) — это даёт чистые границы, но дольше «копирования потока».
* Лимит памяти — мягкий (число потоков Whisper); потоковое декодирование держит память низкой на длинных видео.
* Поддержка перевода субтитров требует LLM; офлайн-перевода нет.

## Тесты
```
python scripts/run_tests.py       # 28 тестов; создают короткое синтетическое видео сами (нужен только FFmpeg)
```
Покрыто: нарезка и длительности, таймлайн, субтитры (SRT/ASS/правка), сведение музыки и ducking, клиппинг, отмена
FFmpeg и задач, отсутствие зависимостей, выбор и дубли, настройки/БД/персонализация, очередь, сквозной прогон по режимам
и возобновление. Свой тестовый материал: любое видео + файл `.srt` рядом, либо `ffmpeg -f lavfi -i testsrc2=size=1280x720:rate=25:duration=60 -f lavfi -i sine=f=300:d=60 -shortest test.mp4`.
